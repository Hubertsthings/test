# Getting started with openbare

A decentralized, censorship-resistant web proxy network

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/openbare.git
cd openbare
```

Available commands:

| Command | Runs |
|---|---|
| `npm run test` | `npm test --workspaces --if-present` |
| `npm run lint` | `npx eslint .` |
